# Zomato Landing Page Clone

This project is a front-end clone of the Zomato landing page, created using HTML and CSS. It showcases various sections of the Zomato homepage, including the hero section, offer cards, collections, and the "Get the App" section.

## Features

- Responsive design for mobile and desktop views.
- Hero section with a background image and search functionality.
- Cards for different offerings like "Order Online" and "Dining".
- A "Collections" section to display curated lists of restaurants.
- A "Get the App" section with a form.
- A detailed footer with navigation links.

## Technologies Used

- HTML5
- CSS3
